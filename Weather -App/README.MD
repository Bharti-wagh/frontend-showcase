# 🌦 Weather App

A simple Weather Application built using HTML, CSS, and JavaScript.

## Features

- Search weather by city
- Live weather data
- Temperature in Celsius
- Weather description
- Humidity
- Wind speed
- Responsive UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API

## How to Run

1. Download the project.
2. Open `script.js`.
3. Add your OpenWeatherMap API Key.
4. Open `index.html`.

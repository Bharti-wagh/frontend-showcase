1. Clone the repository:

```bash
git clone https://github.com/your-username/calculator.git
```

2. Open the project folder.

3. Open `index.html` in your browser or run it using **Live Server** in Visual Studio Code.

## 💡 How It Works

* Click the number buttons to enter values.
* Use the operator buttons (`+`, `-`, `×`, `÷`, `%`) to create expressions.
* Press **=** to calculate the result.
* Press **AC** to clear the display.
* Press **DEL** to remove the last entered character.
